1. /cdd-init

Claude mapeia o projeto inteiro — stack, padrões, convenções — e salva em .cdd/context.md.

.cdd/context.md
✍️

2. Spec

Você descreve o que a feature faz. Claude escreve a especificação. Você aprova.

spec.md
🗺️

3. Plan

Claude planeja arquivos, funções, ordem de implementação, seguindo os padrões do seu projeto.

plan.md
🔨

4. Build

Implementação real, guiada pelo plano. Cada decisão rastreada.

código
🧠

5. Compress

Claude gera a árvore de conhecimento. Você navega pela TUI e marca o que entendeu.

understanding.json
